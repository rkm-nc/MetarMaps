/* ============================================================================ MetarMaps — live regional METAR map ---------------------------------------------------------------------------- R. McMahan rkm-public@gmail.com One file. No build step, no server-side code. Two CDN files (Leaflet) and a handful of public weather feeds. Serve it from any static host. Reference and planning only. Not for navigation. ---------------------------------------------------------------------------- INVOCATION — the query string is the argument list ---------------------------------------------------------------------------- This runs over HTTP, so options arrive in the URL. Nothing about the home field is hardcoded: its coordinates, elevation and site name are resolved against the Aviation Weather Center at startup, which is what makes density altitude correct for whatever field is named. ?apt=KAVL Home field. ICAO or FAA identifier, case insensitive. Three characters take a K prefix, so 1a5, rhp and 24a all resolve. Four characters pass through, so CYYZ and PANC work. Anything else is rejected rather than guessed at. An identifier that resolves to nothing leaves the map on the fallback field and says so, rather than silently showing the wrong airport. Default: K1A5 (Macon County, Franklin, NC). ?span=2.5 Half-width of the opening view, in degrees of latitude. Accepted range 0.2 to 12. Longitude is widened by 1/cos(lat) so the box stays roughly square on the ground. Default: 1.7, about 200 nm across at these latitudes. ?zoom=10 Opening zoom level. Accepted range 5 to 13. Default: 9. ?follow=0 Pins the map to the opening box. Without this the station set follows wherever you pan, one request per pause. Default: follow pans. ?base=light Background map. What governs legibility here is SATURATION, not lightness: the five category colours must be the only saturated things on the screen. Any neutral base works. dark Esri Dark Gray Canvas. Keyless. The default. light Esri Light Gray Canvas. Keyless. Same cartography inverted; better in a bright cockpit or on a projector. relief USGS shaded relief from 3DEP. Keyless, federal, near-grayscale, no labels of its own. The best choice at a mountain field: terrain is the basemap rather than an overlay. topo USGS topographic quads. Keyless. Contours and place detail, but coloured, so the dots fight it. imagery Esri World Imagery. Keyless. Saturated greens and browns; the VFR green suffers. Handsome, not legible. osm OpenStreetMap standard. Keyless, but their tile usage policy is for light traffic only, and the colour competes with the dots. carto CARTO Dark Matter. Requires CONFIG.cartoKey. The hillshade defaults off over relief, topo and imagery, which already carry terrain. ?terrain=1 forces it back. Default: dark. ?radar=1 NEXRAD base reflectivity, on at load. Default: off. ?terrain=0 Shaded relief under the map. Terrain is part of the go/no-go at most fields in the southern Appalachians, so this is on unless you turn it off. Default: on. Both accept 1/0, on/off, true/false, yes/no. A bare flag with no value counts as on, so ?radar and ?radar=1 are the same thing. Either layer can still be toggled from the chip rail once the page is up; these only set the opening state. Examples: /MetarMaps/ K1A5, the default /MetarMaps/?apt=KAVL Asheville /MetarMaps/?apt=KTYS&span=3 Knoxville, wider view /MetarMaps/?apt=KGSP&follow=0 Greenville-Spartanburg, fixed box /MetarMaps/?apt=KAVL&terrain=0 Asheville, relief off /MetarMaps/?base=relief K1A5 on USGS shaded relief /MetarMaps/?apt=KGSP&base=light Greenville-Spartanburg, light base /MetarMaps/?apt=K1A5&radar=1 K1A5 with radar up at load Bookmark the URL and the page comes up on that field every time. Handing a colleague a different link gives them their own tool, not yours. ---------------------------------------------------------------------------- CONFIG — settings that belong to the deployment, not the invocation ---------------------------------------------------------------------------- These are edited in the file below because they are properties of how and where the page is hosted. They are not exposed in the URL on purpose: a query string is for what a pilot chooses, not for what an administrator configured once. proxy The one setting most deployments must change. AWC does not permit cross-origin browser requests, so a browser will normally block a direct call. Point this at your own relay (see worker.js). Leave empty to try AWC directly first. cartoKey Optional. CARTO began requiring an API key on their raster basemaps in August 2026. Empty means the keyless Esri dark base map is used, which is the default and needs no account. home Fallback field. Used only when no ?apt= is supplied, and when a supplied identifier cannot be resolved. spanDeg Default for ?span=. homeZoom Default for ?zoom=. followMap Default for ?follow=. basemap Default for ?base=. The catalogue itself is the BASEMAPS table further down; add an entry there to offer another. showRadar Default for ?radar=. showTerrain Default for ?terrain=. markerScale Global size multiplier for the station glyphs, with markerGrowth markerGrowth controlling how fast they grow with zoom and markerMin markerMin/markerMax bounding the result. markerMax refreshMs Poll interval. AWC's limit is 100 requests per minute across all clients, so five minutes is polite. Leave it alone. staleMin Age past which an observation is drawn as no current data rather than in its last category. A stale green dot over a field that went IFR two hours ago is the failure that hurts someone, so this is deliberately conservative. maxSpanDeg Widest box ever requested, however far you zoom out. AWC truncates any response at 400 stations; the status bar says so when that happens. maxMarkers Above this count the display thins: stations are bucketed into screen cells and one is kept per cell, always the one in the WORST condition. Thinning may hide good news. It must never hide weather. ---------------------------------------------------------------------------- DATA ---------------------------------------------------------------------------- METAR, AIRMET/SIGMET NOAA / Aviation Weather Center needs the proxy Winds aloft Open-Meteo pressure levels cross-origin open Radar NOAA NEXRAD via Iowa State tiles, no key Terrain, base, labels Esri / USGS tiles, no key Raw METAR text is parsed here rather than trusting decoded fields, so the same code path serves any feed that returns a raw report. ========================================================================== */ Macon County · K1A5 · METAR map
